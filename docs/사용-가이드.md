# 사용 가이드

처음 실행부터 각 기능 사용법까지 순서대로 설명합니다.

## 1. 환경 준비

### Docker로 실행 (권장)

```bash
cp .env.example .env
```

`.env`에서 최소 아래 값을 채웁니다.

```
SECRET_KEY=<아래 명령으로 생성한 값>
POSTGRES_PASSWORD=<원하는 비밀번호>
```

SECRET_KEY 생성:
```bash
python -c "import secrets; print(secrets.token_urlsafe(64))"
```

실행:
```bash
docker compose up --build
```
→ 브라우저에서 http://localhost:8080

### 로컬 개발로 실행

```bash
# 백엔드
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1     # Windows
pip install -r requirements.txt
# backend/.env 에 SECRET_KEY, DATABASE_URL 설정
uvicorn app.main:app --reload

# 프론트 (새 터미널)
cd frontend
npm install
npm run dev
```
→ http://localhost:5173

## 2. 회원가입 / 로그인

1. 첫 화면에서 **회원가입** → 이메일, 비밀번호(8자 이상), 이름 입력.
2. 가입하면 자동 로그인되어 대시보드로 이동합니다.

## 3. 대시보드 (Study 로고 클릭 시 이동)

- **Today**: 오늘 공부 시간, 평균 집중도, 루틴/일정 진행률.
- **This Month**: 이번 달 총 공부 시간, 공부한 날, 일별 공부량 그래프, 과목별 비중.
- 모든 수치는 실제 기록에서 자동 집계됩니다.

## 4. 공부 타이머

1. **과목 선택** (없으면 "과목 관리"에서 대분류/소분류 추가).
2. **시작** → 공부 시작.
3. **일시정지(휴식)** → 휴식 시간 측정 / **공부 재개** → 다시 공부.
4. **중지(종료)** → 집중도(5단계)와 메모를 입력하고 **기록 저장**.

## 5. 과목 관리 (대분류 / 소분류)

- 예: 대분류 "영어" → 소분류 "영어독해", "영어단어".
- 타이머와 루틴에서 같은 과목 목록을 사용합니다.
- 소분류 아래에는 다시 하위 과목을 만들 수 없습니다(2단계).

## 6. 일정 캘린더

1. 상단에서 연/월을 선택하거나 화살표로 이동, "오늘"로 복귀.
2. 날짜를 선택하고 일정을 추가.
3. 체크박스로 완료 표시 → 완료율이 진행률 막대로 보입니다.

## 7. 공부 캘린더 (루틴 / 기록 탭)

### 루틴 탭

- 반복할 루틴을 추가(과목 연동 가능).
- 각 날짜에서 완료 체크 → 진행률 표시.
- **중요**: 루틴을 수정하면 오늘 이후로만 바뀌고, **과거 날짜의 루틴은 그대로 유지**됩니다.

### 기록 탭

- 타이머로 저장한 기록이 표시됩니다.
- **직접 추가**로 수동 기록도 가능(공부/휴식 분, 집중도, 메모).
- 각 기록을 **수정/삭제**할 수 있습니다.

## 8. 관리자 학습 가이드

관리자만 상단 네비에 "학습 가이드"가 보입니다.

관리자 승격:
```bash
cd backend
python -m scripts.make_admin your@email.com
```

승격 후 다시 로그인하면 프론트/백/클라우드/정보보안 학습 가이드에 접근할 수 있습니다.
(정보보안은 교육·방어 중심 자료입니다.)

## 9. 모니터링 (선택)

```bash
docker compose -f docker-compose.yml -f docker-compose.monitoring.yml up --build
```

- Grafana: http://localhost:3000 (`.env`의 `GRAFANA_ADMIN_PASSWORD`로 로그인)
- 백엔드 요청률/지연/상태코드와 로그를 대시보드에서 확인합니다.

## 문제 해결

- **로그인이 안 돼요**: `SECRET_KEY`가 설정됐는지 확인(미설정 시 백엔드가 시작되지 않음).
- **DB 연결 오류**: `DATABASE_URL`이 올바른지, PostgreSQL이 실행 중인지 확인.
- **포트 충돌**: 이미 사용 중인 포트가 있으면 `.env`의 포트 값을 변경.
